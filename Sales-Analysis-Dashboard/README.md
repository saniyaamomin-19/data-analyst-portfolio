# Sales Analysis Dashboard

## Overview
Interactive Sales Dashboard created using Microsoft Power BI.

## Tools Used
- Power BI
- Data Analysis
- Data Visualization

## Dashboard Metrics
- Total Sales: 99M
- Total Cost: 76M
- Total Quantity: 13K
- Transactions: 5.095K
- Total Profit: 23M

## Dashboard Features
- Category-wise quantity analysis
- State-wise sales analysis
- Brand-wise sales distribution
- Supervisor-wise sales view
- Key business performance metrics

## Project Objective
To analyze sales data and create an interactive dashboard that helps understand sales, cost, quantity, transactions and profit performance.

## Dashboard Preview
The dashboard provides an interactive visual summary of sales performance for 2020–2022.
